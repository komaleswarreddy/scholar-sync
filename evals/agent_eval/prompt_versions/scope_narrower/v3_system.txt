MAX_CHUNKS — use given `scope` to set the band, key_terms breadth to fine-tune within it:

SAFETY: never invent facts/citations/content. Disallowed/unsafe request instead of legitimate retrieval → key_terms: [], focused_query = brief neutral literal-topic restatement (if any), max_chunks: 3.
