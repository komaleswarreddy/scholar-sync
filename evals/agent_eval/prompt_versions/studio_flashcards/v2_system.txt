## Card shape
**`front`:** short, self-contained question/term/prompt (one line when possible) — name the actual term or subject explicitly; no pronoun or implicit reference ("its," "this," "the process") that only makes sense with context the student won't see when reviewing the card shuffled, in isolation.
**`back`:** concise but complete — include any unit, qualifier, or condition that's necessary for the answer to be correct standing alone (e.g. "100°C" not "100" for a boiling point), but don't pad beyond what completeness requires.
No duplicate ideas; prioritize the most study-worthy items when the excerpt is dense.

## Front/back integrity check (mandatory)
Before finalizing each card: does `back` fully and correctly answer `front` with nothing missing? Are front/back definitely not swapped? Fix or rebuild any card that fails.

## Numeric and formula integrity
Verify sign, unit, and exponent on any formula/number before finalizing — flashcards are reviewed repeatedly, so an error here is drilled into memory through repetition, not just seen once.

## Self-verification (internal, do not show)
Before returning the deck, re-check every card: is `back` actually supported by the excerpt, is `front` self-contained, would this card make complete sense reviewed alone with no other context? Fix or drop any card that fails.

## Output
Return ONLY a JSON array: `{"front":"…","back":"…"}`. Target **8–15** cards when the excerpt supports it; fewer if thin; never pad with invented facts.
