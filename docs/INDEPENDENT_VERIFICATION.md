# Independent Verification (TestSprite)

Second line of defense alongside the layered local production gate (`scripts/run_prod_gate.py`). Independent tests catch assertion drift and environment-specific failures the local gate may miss (see **ING-03**: product accepts encrypted PDF upload with password at indexing time; an early TestSprite plan expected HTTP 400 without password).

## When to run

- Before demo or production launch
- After any change to ingest, chat/stream, or auth middleware
- After fixing pool exhaustion or classroom load behavior

## Pass bar

- **≥ 18 / 23** TestSprite cases pass (TC001 health + 22 ING/RET tests)
- Failures triaged as: **infra** (cloud sandbox, JWT, imports) vs **product** vs **stale assertion**

## Prerequisites

1. API running locally: `python -m uvicorn apps.api.main:app --host 127.0.0.1 --port 8000` (no `--reload` during load tests)
2. `.env` with `DATABASE_URL` (prefer Supabase transaction pooler port **6543**), `OPENAI_API_KEY`, `PINECONE_API_KEY`
3. Inlined tests in `testsprite_tests/ING-*.py` and `RET-*.py` (generated by `scripts/inline_testsprite_cloud.py` — do not rely on cloud `fixture_payloads` imports)

## Run via TestSprite MCP

1. Ensure `testsprite_tests/testsprite_backend_test_plan.json` matches product behavior (especially ING-03)
2. Execute inlined tests against `http://localhost:8000` in development mode
3. Record run ID and results in `testsprite_tests/tmp/test_results.json`
4. Append summary to [PRODUCTION_TEST_REPORT.md](PRODUCTION_TEST_REPORT.md) § Independent verification

## Run inlined tests locally

```powershell
$env:INTEGRATION_TESTS = "1"
$env:NOTEBOOKLM_API_URL = "http://127.0.0.1:8000"
python scripts/run_testsprite_local.py
```

Writes `evals/reports/testsprite_local_summary.json`. Exit 0 when ≥18/22 pass.

## Test vs product decisions

| ID | Historical test expectation | Actual product behavior | Resolution |
|----|----------------------------|------------------------|------------|
| ING-03 | 400 on upload without password | 200 upload; password required at indexing via `pdf_password` | Inlined test uploads with `pdf_password=testpass` |

## Relationship to local gate

| Layer | Role |
|-------|------|
| Local prod gate | **Primary** — pytest, retrieval_eval, classroom Locust, RET-04 export |
| TestSprite / black-box | **Independent** — challenges assumptions, catches spec drift |
| Curriculum sign-off | **Human** — RET-04 ≥95%, ING-08 ≥90% via `scripts/verify_curriculum_signoff.py` |

Retrieval is **not** production-ready until local gate, classroom load, RET-04 export, curriculum sign-off, and independent verification targets are all met.
